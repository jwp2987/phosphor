## How each verdict was reached

- **Fix commits**: `git log integ/r14 --grep '#N'`, plus the commits of any merge whose message names the issue. A commit is 'in the run' when it is an ancestor of `501a18469`.
- **Unit tests**: the `#[test]` functions the fix commits added. A test counts when its name exists at `501a18469`, its package is in `test-linux` (`-p warp -p warp_tui --lib`), `test-warpui-core` or `test-workspace-rest`, and it is not among the run's 4 failures. The nextest log is not in the archive, so 'ran' rests on that rule, and the 55 skipped tests are not named. The unit jobs ran on Linux only.
- **App rows**: `app/{wayland,lab-wayland,macos,windows}/results.json`. PASS, FAIL, SKIP and NOREF are quoted as recorded; reasons are quoted from the row's detail.
- **Guards**: the `guards` job succeeded; it runs the appci self-test (`script/realapp/appci/selftest.py`), `check_ftl_escapes`, `check_input_path_timers` and the release-gate self-test. For a harness issue the self-test check is the test.
- **Strictness**: merged is not proven. A NOREF or SKIP is not a pass. A case that is not in the fix tier did not run. A unit test proves the rule it asserts: where the issue is about a real session, a platform or a time budget, unit tests alone give PROVEN-PARTLY. An issue is PROVEN on unit tests alone only when it is itself a rule in the code (a timer policy, a routing rule, a state-machine step, a remote-backend contract).
- **Limit of this pass**: unit tests were matched to issues by their names, the fix commit's subject and `docs/testing.md`, not by reading every assertion. Before closing an issue on a single unit test, read that test.
- **Verdicts**: PROVEN = every judging test passed on every platform the issue is about. PROVEN-PARTLY = passes somewhere, NOREF / SKIP / FAIL / not run elsewhere. FAILING = the row that judges the issue fails and nothing passes in its place. NOT-JUDGED = tests exist but none judged (not run, SKIP, NOREF, or the fix is newer than the run). NO-TEST = nothing exercises it. NOT-A-FIX = the label is wrong.
