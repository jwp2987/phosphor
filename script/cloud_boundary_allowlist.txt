# modules. One line per RESOLVED PATH: "<file> <fully-qualified-path>".
#
# This list may SHRINK freely. Adding to it means the fork took on another
# dependency on retained cloud scaffolding, and needs maintainer sign-off plus
# a tracking issue (AGENTS.md 5.10).
#
# 2026-08-21 REBASELINE #2 -- format changed from source lines to resolved paths.
#
# The previous format recorded the matched SOURCE LINE, so 154 of 442 entries
# were the opaque string "<file> use crate::{". An adversarial probe defeated
# it by inserting a brand-new cloud import into a brace block that was already
# allowlisted under one of those entries: the guard reported ok. Recording the
# resolved path instead means a new import is a new line, always.
#
# The count rises from 442 to 1018 because one `use crate::{a, b, c}` statement
# is now three entries rather than one. It is the same surface, described
# precisely for the first time -- not new dependencies.
#
# Two of these launder the boundary at the crate root and should be REMOVED
# rather than allowlisted permanently:
#   app/src/lib.rs                pub use crate::server::telemetry::*
#   app/src/drive/folders/mod.rs  pub use crate::server::ids::FolderId
# app/src/lib.rs:302-303 cites THIS GUARD as the reason its re-export exists.
#
